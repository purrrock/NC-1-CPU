# Эмулятор микропроцессора NC-1 и отладочной платы

## Описание
Данная директория содержит эталонный программный эмулятор 4-битного RISC-микропроцессора NC-1 (архитектура v4.5) и графический интерфейс (GUI) аппаратно-отладочной платы, реализованные на языке Python. 

Эмулятор выполняет потактовое и поинструкционное моделирование вычислительного ядра, подсистемы управления памятью (двухбанковая Гарвардская архитектура ROM/RAM, Shadow Write, кросс-банковый доступ LDRA) и периферийных устройств (Memory-Mapped I/O, включая контроллер синхронного накопителя).

## Системные требования
* Python 3.10 или новее.
* Tkinter.

## Структура модулей

* `nc1.py` — Точка входа в программу. Инициализирует аппаратные компоненты и запускает событийный цикл GUI.
* `cpu.py` — Ядро процессора (Central Processing Unit, ISA v4.5). Реализует цикл выборки, декодирования и выполнения (Fetch-Decode-Execute) инструкций переменной длины (1–4 ниббла). Содержит логику АЛУ, управление флагами (Z, C, M), декодирование префикса EXT (0xF), команды относительного (JZR, JCR, JR) и абсолютного перехода, а также аппаратный стек (0xE0–0xEF).
* `registers.py` — Регистровый файл. Управляет 8 ортогональными 4-битными регистрами (A, B, X, Y, SP, FL, PCH, PCL). Содержит аппаратную логику уведомления о прямой записи в PCL (callback `on_pcl_write`), составные свойства для 8-битной адресации (PC, ADDR) и маскирование битов регистра флагов FL (Bit 3 Reserved, Bit 2 M, Bit 1 C, Bit 0 Z).
* `mmu.py` — Блок управления памятью (Memory Management Unit). Разделяет адресное пространство (0x00–0xFF) на системный (ROM) и пользовательский (RAM) банки на основе флага M. Содержит логику теневой записи (Shadow Write в RAM), кросс-банкового чтения (LDRA), обработки портов MMIO (0xF0–0xF9) и встроенный контроллер потокового накопителя (`StorageDrive`).
* `assembler.py` — Интегрированный ассемблер (ISA v4.5). Выполняет двухпроходную трансляцию мнемоник в шестнадцатеричные нибблы (инструкции длиной 1–4 ниббла). Поддерживает расчёт относительных смещений для прыжков (диапазон от -8 до +7), директивы `ORG`, `DB`, `DN`, а также псевдоинструкцию `NOP` (транслируется в `JR +0` / `0xE0`) и останов `HLT` (`0xFF`).
* `gui.py` — Интерфейс отладочной платы. Включает матричную клавиатуру 4x4 (Hex 0-F), четыре 7-сегментных индикатора, визуальный контроль флагов регистра FL, текстовый редактор кода и двухоконный просмотрщик дампа памяти (RAM/ROM) с подсветкой текущей инструкции.

## Карта периферии (MMIO)

| Адрес | Устройство | Доступ | Описание |
|---|---|---|---|
| `F0–F3` | DISP_0..3 | R/W | 7-сегментные Hex-индикаторы. F3 — старший (левый), F0 — младший (правый). |
| `F4` | GPI_KBD | R | Бит 0: флаг удержания клавиши (1 = нажата, 0 = отпущена). Биты 1..3: линии GPI подтянуты к 0. |
| `F5` | KBD_CODE | R | Скан-код последней нажатой клавиши (0x0–0xF). |
| `F6` | GPO_AUD | R/W | Бит 0: управление динамиком (1 = Вкл, 0 = Выкл). Биты 1..3: линии GPO. |
| `F7` | RNG | R | Аппаратный генератор псевдослучайных чисел (0x0–0xF). |
| `F8` | STORAGE_DAT | R/W | Буфер данных синхронного накопителя (автоинкремент указателя при чтении/записи). |
| `F9` | STORAGE_CMD | R/W | Регистр управления и статуса накопителя (Запись: Bit 0 = MOTOR, Bit 1 = MODE; Чтение: Bit 0 = READY, Bit 1 = EOF). |

## Запуск

Для старта эмулятора в режиме отладочной платы выполните команду в директории emu:

```bash
python nc1.py
```

## Использование отладчика
1. Введите ассемблерный код в поле **Code Editor** или загрузите из файла (`.asm`).
2. Нажмите **Assemble to ROM** (или RAM) для компиляции кода в системный банк памяти (вкладка ROM станет активной).
3. Используйте кнопку **Step** для пошагового выполнения инструкций с трассировкой изменений в регистрах.
4. Используйте кнопку **Run** для автоматического исполнения программы.
5. Аппаратный сброс процессора осуществляется кнопкой **Reset**.
