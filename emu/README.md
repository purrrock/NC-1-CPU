# Эмулятор микропроцессора NC-1

## Описание
Данная директория содержит эталонный программный эмулятор 4-битного RISC-микропроцессора NC-1 (архитектура v4.0) и графический интерфейс (GUI) аппаратно-отладочной платы, реализованные на языке Python. 

Эмулятор выполняет потактовое и поинструкционное моделирование вычислительного ядра, подсистемы управления памятью (Shadow Write, переключение банков ROM/RAM) и периферийных устройств (Memory-Mapped I/O).

## Системные требования
* Python 3.10 или новее.
* Tkinter.

## Структура модулей

* `nc1.py` — Точка входа в программу. Инициализирует аппаратные компоненты и запускает событийный цикл GUI.
* `cpu.py` — Ядро процессора (Central Processing Unit). Содержит цикл выборки, декодирования и выполнения (Fetch-Decode-Execute) инструкций переменной длины (1-3 ниббла). Реализует логику АЛУ и аппаратный стек (D0–EF).
* `registers.py` — Регистровый файл. Управляет 8 ортогональными 4-битными регистрами (A, B, X, Y, SP, FL, PCH, PCL). Содержит аппаратную логику прерывания конвейера при прямой записи в PCL (JUMP-on-PCL-write) и маскирование битов регистра флагов (R, M, C, Z).
* `mmu.py` — Блок управления памятью (Memory Management Unit). Разделяет адресное пространство (0x00–0xFF) на системный (ROM) и пользовательский (RAM) банки на основе флага M. Содержит логику обработки MMIO и обратные вызовы (callbacks) для синхронизации с GUI.
* `assembler.py` — Интегрированный ассемблер (ISA v4.0). Компилирует мнемоники исходного кода в шестнадцатеричные нибблы.
* `gui.py` — Интерфейс отладочной платы. Включает матричную клавиатуру 4x4 (Hex 0-F), четыре 7-сегментных индикатора, визуальный контроль флагов регистра FL, текстовый редактор кода и двухоконный просмотрщик дампа памяти (RAM/ROM) с подсветкой текущей инструкции.

## Карта периферии (MMIO)

| Адрес | Устройство | Доступ | Описание |
|---|---|---|---|
| `F0–F3` | DISP_0..3 | W | 7-сегментные Hex-индикаторы. F3 — старший (левый), F0 — младший (правый). |
| `F4` | KBD_STAT | R | Флаг удержания клавиши (1 = нажата, 0 = отпущена). Имитация регистра-защелки. |
| `F5` | KBD_CODE | R | Скан-код последней нажатой клавиши (0x0 - 0xF). |
| `F6` | AUDIO | W | Контроллер динамика (Бит 0: 1 = Вкл, 0 = Выкл). |
| `F7` | RNG | R | Аппаратный генератор случайных чисел. |

## Запуск

Для старта эмулятора в режиме отладочной платы выполните команду в корневой директории проекта:

```bash
python nc1.py
```

## Использование отладчика
1. Введите ассемблерный код в поле **Code Editor** или загрузите из файла (`.asm`).
2. Нажмите **Assemble to ROM** для компиляции кода в системный банк памяти (вкладка ROM станет активной).
3. Используйте кнопку **Step** для пошагового выполнения инструкций с трассировкой изменений в регистрах.
4. Используйте кнопку **Run** для автоматического исполнения программы.
5. Аппаратный сброс процессора осуществляется кнопкой **Reset**.
