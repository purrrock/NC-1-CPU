# NC-1 Nano-Monitor

Nano-Monitor — минимальная ROM-мониторная программа для учебного 4-битного процессора NC-1.

Монитор позволяет с 16-клавишной hex-клавиатуры:

- загружать программу в User RAM;
- выбирать адрес загрузки;
- запускать программу с указанного адреса;
- возвращаться из пользовательской программы обратно в монитор.

Монитор работает в System Mode и размещается в System ROM.

## Запуск

После аппаратного сброса NC-1 начинает выполнение с адреса `0x00`, где находится Nano-Monitor.

Монитор ожидает одну команду.

Поддерживаются две команды:

| Клавиша | Команда | Назначение |
|---|---|---|
| `A` | `LOAD` | Загрузить программу в RAM |
| `B` | `RUN` | Запустить программу из RAM |

Все остальные клавиши в командном режиме игнорируются.

## LOAD

Нажмите:

```text
A
```

После этого необходимо ввести двухзначный hex-адрес начала программы.

Например:

```text
A 2 0
```

означает:

```text
LOAD 0x20
```

После ввода адреса монитор переходит в режим загрузки машинного кода.

Далее каждый введённый hex-ниббл записывается в последовательные ячейки User RAM:

```text
0x20
0x21
0x22
0x23
...
```

Например:

```text
A 2 0
1 2 3 4 5 6
F 0
```

запишет:

```text
RAM[0x20] = 0x1
RAM[0x21] = 0x2
RAM[0x22] = 0x3
RAM[0x23] = 0x4
RAM[0x24] = 0x5
RAM[0x25] = 0x6
```

Последовательность `F0` является признаком завершения загрузки и в память не записывается.

После `F0` монитор возвращается в командный режим.

## Как записать `F` как данные

Поскольку `F0` используется как признак конца загрузки, для записи произвольного `F` используется escape-последовательность:

```text
FF
```

То есть:

```text
FF
```

означает «записать литеральный `F`».

Например, чтобы записать программу:

```text
F4 1 2 F0
```

необходимо ввести:

```text
FF 4 1 2 FF 0 F0
```

Последнее `F0` завершает загрузку.

Таким образом, пользователь может загрузить произвольную последовательность машинных нибблов, включая инструкции `SYS`.

## Индикация

Во время загрузки четыре 7-сегментных индикатора используются для отображения состояния загрузчика.

Основная информация:

```text
DISP_3 DISP_2 DISP_1 DISP_0
   адрес      введённый  режим
              ниббл
```

Старшие и младшие нибблы текущего адреса позволяют контролировать, куда будет записан следующий машинный ниббл.

Последний введённый ниббл отображается отдельно, что позволяет контролировать ввод с клавиатуры.

## RUN

Для запуска программы нажмите:

```text
B
```

затем введите двухзначный hex-адрес.

Например:

```text
B 2 0
```

запускает программу с адреса:

```text
0x20
```

Монитор переключает процессор в User Mode и передаёт управление программе.

## Требования к пользовательской программе

Программа должна находиться в User RAM.

Основная область пользовательского кода:

```text
0x10 .. 0xCF
```

Адреса `0x01..0x0F` зарезервированы ABI монитора/ОС и не должны использоваться пользовательской программой без понимания соглашений о сохранении состояния.

Области памяти:

```text
0x00       Entry Vector
0x01-0x0F  Zero Page / OS state
0x10-0xCF  Program Space
0xD0-0xDF  Buffer Space
0xE0-0xEF  Hardware Stack
0xF0-0xFF  MMIO
```

## Возврат в Nano-Monitor

Пользовательская программа должна возвращать управление монитору через `SWI`:

```asm
SYS 4
```

Ассемблер также может использовать мнемонику:

```asm
SWI
```

Выполнение `SWI` переводит процессор в System Mode и передаёт управление единой точке входа `0x00`.

После этого Nano-Monitor снова переходит в командный режим.

Простейшая программа:

```asm
ORG 0x20
LDI 0x5
MOV A,B
SWI
```

## HLT

Инструкция:

```asm
HLT
```

не возвращает управление Nano-Monitor.

`HLT` полностью останавливает процессор до аппаратного сброса.

Поэтому для завершения пользовательской программы рекомендуется использовать `SWI`.

## Ограничения

Nano-Monitor предназначен для загрузки и запуска небольших учебных программ.

Program Space пользователя ограничен:

```text
0x10 .. 0xCF
```

то есть:

```text
192 nibble
```

Загрузка за пределы `0xCF` не должна использоваться.

Аппаратный стек расположен в:

```text
0xE0 .. 0xEF
```

и используется инструкциями `CAL`/`RET`.

## Пример полного сеанса

Допустим, необходимо загрузить программу по адресу `0x20`.

Программа:

```asm
ORG 0x20
LDI 0x7
MOV A,B
SWI
```

Машинная последовательность:

```text
1 7 2 1 F 4
```

Поскольку `F` используется как escape:

```text
A 2 0
1 7 2 1 FF 4 F 0
```

После `F0` ввод завершён.

Запуск:

```text
B 2 0
```

Процессор передаст управление адресу `0x20`.

После выполнения `SWI` Nano-Monitor снова получит управление и будет ожидать следующую команду.

## Команды Nano-Monitor

```text
A HH LL ... F0    Load program
B HH LL            Run program
```

Где `HH` и `LL` — старший и младший hex-нибблы адреса.

### Краткая памятка

```text
A HH LL   загрузить программу
F0        закончить загрузку
FF        записать литеральный F
B HH LL   запустить программу
SYS 4     вернуть управление монитору
```
