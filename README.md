# Проект NC-1: 4-битный CPU и Эмулятор

**NC-1** — это минималистичный 4-битный микропроцессор с набором команд переменной длины (Variable-Length ISA, v4.4), спроектированный для образовательных целей, экспериментов с ПЛИС (FPGA), изучения цифровой логики и разработки программных эмуляторов. 

Данный репозиторий содержит полную техническую спецификацию архитектуры, а также визуальный программный эмулятор отладочной платы, написанный на Python. Архитектура делает упор на экстремально высокую плотность кода и минимальный аппаратный размер, оставаясь при этом достаточно выразительной для поддержки встроенного Nano-Monitor, пользовательских приложений и периферии с отображением в память (MMIO).

---

## Ключевые особенности

**Аппаратная часть (Архитектура v4.4):**
- **4-битная архитектура** с 8-битной шиной адреса (512 нибблов общего пространства: 256 ROM + 256 RAM).
- **Модифицированная Гарвардская архитектура:** Раздельные банки ROM (Система / Nano-Monitor) и RAM (Пользователь).
- **Variable-Length ISA (1..4 ниббла):** Высочайшая плотность кода благодаря 1-ниббловым операциям памяти (`LDR`, `STR`), стека (`PHA`, `PLA`) и инкремента/декремента 16-битных указателей (`INX`, `DEX`).
- **Страничный аппаратный стек:** 4-битный регистр SP аппаратно привязан к странице RAM `0xE0..0xEF` (вызовы `CAL` и контекст `PHA/PLA`).
- **Аппаратное переключение банков (`XBNK`):** Телепортация исполнения между ROM и RAM без изменения траектории `PC` и порчи арифметических флагов.
- **Механизм Shadow Write (Теневая запись):** Любая запись в память всегда физически направляется в RAM, что позволяет коду из ROM инициализировать пользовательское ОЗУ.
- **Периферия MMIO:** Прямое управление дисплеями и клавиатурой по адресам `0xF0..0xFD`.
- **Ортогональный регистровый файл:** `PC`, `SP` и регистр флагов `FL` доступны как обычные регистры.
- **Чистый возврат (`BOOT`):** Аппаратная инструкция программного сброса для элегантного возврата из пользовательской RAM обратно в ROM-Монитор.

**Организация памяти:**
- `0x00`: Аппаратный вектор сброса (Hardware Reset).
- `0x01` – `0xDF`: Унифицированное пространство кода и данных пользователя (User Program & Data Space).
- `0xE0` – `0xEF`: Аппаратный стек вызовов и данных.
- `0xF0` – `0xFD`: Порты ввода-вывода (MMIO).
